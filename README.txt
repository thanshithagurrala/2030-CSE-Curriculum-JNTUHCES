HKAIVERSE Curriculum Intelligence Challenge – Website

Files:
- index.html: main website
- style.css: styling and responsive layout
- script.js: 2030 curriculum data and semester filter
- README.txt: project notes

How to run:
1. Keep all four files in the same folder.
2. Open index.html in a browser.
3. Use the Semester dropdown to view one semester and its credits.

Interactive feature:
The semester dropdown filters the proposed 2030 curriculum and displays the selected credit total. The complete degree is 160 credits.

For submission:
Upload the 10_Website folder to the public GitHub repository and publish it with GitHub Pages, Netlify, Vercel, or another suitable static-site host. Test the public URL from another browser/device before submitting.
